# カホン・リズム道場 🥁

スマートフォンのブラウザで遊べる、**カホンのリズム学習ゲーム**です。
画面のカホンを叩く位置で音色（奏法）が変わり、8ビート・16ビートの基礎から J-POP・アニソン・ボカロで使われる複雑なリズムまで、遊びながら身につけられます。

- HTML / CSS / JavaScript のみ（ビルド不要・外部ライブラリなし）
- 音はすべて Web Audio API でブラウザ内合成（音源ファイル・サーバー・有料APIなし）
- 進捗・設定・マイパターンは端末内（localStorage）に保存
- 一度開けばオフラインでも動作（Service Worker）
- GitHub Pages で無料公開できる構成

## 遊べる内容

| 機能 | 内容 |
| --- | --- |
| 練習モード | マス目譜面・お手本再生・BPM変更（40〜240）・メトロノーム・伴奏・ループ判定（正確さ%）・**段階的テンポアップ**（成功したら自動でBPMアップ）・解説 |
| 音ゲーモード | 横に流れるノーツ、PERFECT / GREAT / GOOD / MISS 判定、スコア・コンボ、ランク（SS〜D）、自己ベスト、早い／遅い傾向のアドバイス |
| カホン演奏 | ベース（中央）・スラップ（上端）・ゴースト（上部の左右端）・オープントーン（上から2段目）・ミュート（下端）。マルチタッチ対応 |
| リズム分解 | ドラム（ハイハット・スネア・キック）に分けて聴き、①→④の手順でカホンに置き換える |
| リズム研究室 | マスをタップして編集、ゴースト追加・食い・裏拍アクセント・ベース／スラップ移動などの自動変形、元パターンとの聴き比べ、**お題（6種）**、ドラム譜→カホン譜の変換、マイパターン保存 |
| 曲に合わせて作る | 曲のBPM（タップ測定可）・拍子・スタイルから**オリジナル**の練習譜面を自動生成 |
| 耳コピ | 譜面を隠してお手本だけを聴いて叩く |
| フリー演奏（即興） | コード進行の伴奏＋メトロノームに合わせて自由に演奏、拍からのズレをメーター表示 |
| 奏法ガイド | 5つの奏法の解説と音、聴き分けクイズ |
| 設定 | 音量、タイミング補正（タップで自動測定）、判定の厳しさ、ノーツ速度、データのバックアップ／復元 |

収録パターン：34種（基本リズム13・ジャンル別10・J-POP/アニソン/ボカロ11）。
4ビート / 8ビート / 16ビート / ハーフタイム / シャッフル / 三連符 / 3拍子 / 6/8 / フィルイン、ロック / ポップス / バラード / ファンク / 4つ打ち / ボサノバ / レゲエ / ジャズ / ラテン、J-POP王道8ビート / 16ビート / ハネ / 食い / 疾走2ビート / キメ / 3・3・2 / ボカロ高速 / ポリリズム / 7/8 など。

> 収録パターンと伴奏はすべてオリジナルです。市販楽曲の音源・譜面は収録していません。

## スマホだけで公開する方法（GitHub Pages・無料）

1. スマホのブラウザで GitHub のこのリポジトリを開く（「デスクトップ版」表示にすると操作しやすい）
2. **Settings → Pages** を開く
3. 「Build and deployment」の Source を **Deploy from a branch** にする
4. Branch で公開したいブランチ（例：`main`）と `/ (root)` を選び **Save**
5. 数分後、`https://<ユーザー名>.github.io/rhythm-game/` で遊べます

ホーム画面に追加すると、アプリのように全画面で起動できます。

## スマホでの遊び方のコツ

- 音が出ないとき：音量を上げ、iPhone はマナーモードを解除してください。最初に画面をタップすると音声が有効になります。
- 判定がずれると感じたら：設定 →「タップで自動測定」。Bluetoothイヤホンは遅延が大きいため、スピーカーか有線を推奨します。
- PCのキーボードでも叩けます：F=ベース, J=スラップ, D/K=ゴースト, L=オープン, V=ミュート

### パターンの追加方法

`js/patterns.js` の `RAW` 配列に追加します。1文字＝1ステップです。

```js
{ id: 'my-beat', cat: 'jpop', level: 3, name: '名前', bpm: 120, beats: 4, sub: 4,
  cajon: 'B.gB S.g. B.gB S.gg',   // B=ベース S=スラップ g=ゴースト O=オープン M=ミュート .=休み
  accent: '.... x... .... x...',  // x=アクセント（省略可）
  desc: '説明' }
```

`cajon` の代わりにドラム譜 `k`（キック）`s`（スネア）`h`（ハイハット）を書くと、自動でカホン譜に変換され、「ドラム分解」も使えるようになります。
